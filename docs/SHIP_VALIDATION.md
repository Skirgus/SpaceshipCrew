# Валидация корабля

Два независимых статуса чертежа: **можно сохранить** и **готов к полёту** (выбор для новой игры).

## Обязательные модули (минимум один экземпляр каждого типа)

| `EShipModuleType` | Назначение |
|-------------------|------------|
| `Reactor` | Питание систем |
| `Engine` | Тяга и манёвренность |
| `FuelTank` | Запас топлива |
| `OxygenTank` | Запас кислорода |
| `Airlock` | Вход/выход экипажа |
| `Bridge` | Командирский мостик |

Повторы одного типа (несколько баков, двигателей) допустимы.

## Необязательные модули

| Тип | Роль |
|-----|------|
| `Corridor` | Соединение отсеков |
| `CargoHold` | Груз и контракты доставки |
| `ScienceLab` | Исследования |
| `PassengerCabin` | Пассажиры |
| `Turret` | Вооружение |
| `ShieldGenerator` | Щиты |
| `Sensor` | Обнаружение |
| `Communication` | Связь |
| `SecurityPost` | Внутренняя безопасность |

## Матрица действий

| Действие | Условие |
|----------|---------|
| Сохранить в конструкторе | Непустой layout; все `ModuleId` есть в каталоге (`ValidateDocumentForSave`) |
| Открыть в конструкторе | То же для `ModuleId`; состав и стыковка не проверяются |
| Выбрать для новой игры | `ValidateDocumentForPlay`: нет ошибок стыковки **и** все 6 обязательных типов |

## API (C++)

- `FShipPlayRequirements` — список обязательных типов и сообщения об отсутствии.
- `FShipBuildValidationResult::bIsPlayReady`, `PlayBlockers` — результат `FShipBuildDomainModel::Validate()`.
- `FShipBlueprintSerializer::ValidateDocumentForPlay` — проверка сохранённого/чернового документа.
- `UShipBlueprintSessionSubsystem::TrySetSelectedShipForNewGame` — установка корабля для T04 только при готовности.

## UI конструктора

- **ГОТОВ К ПОЛЁТУ** — `bIsPlayReady`.
- **ЧЕРНОВИК** — иначе; сохранение по-прежнему доступно.
- Чеклист (C): ошибки сборки → не готов к полёту → советы.

В списке кораблей черновики помечаются суффиксом «(черновик)»; вход в конструктор не блокируется.

## Схема чертежа и сетка

- **`SchemaVersion`**: текущая **2** — `GridPos` в сохранённом чертеже = min-угол footprint (см. [SHIP_BUILDER_GRID_RU.md](SHIP_BUILDER_GRID_RU.md)).
- Чертежи v1 мигрируют при открытии в конструкторе; после миграции сохраните документ.
- Размещение и стыковка: panel-сетка 400×400×300 см, стыковка panel-socket к panel-socket.
